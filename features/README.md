# features/

Lógica y componentes específicos de cada dominio, un patrón calcado del `features/` de bondiya.

- `subtes/{components,hooks}/` — línea de subte, forecast, alertas. Se llena en Sprint 2 (datos) y Sprint 3 (forecast/alertas en vivo). Referencia: `bondiya/features/subtes/`.
- `paradas/{components,hooks}/` — estaciones, `useParadaDetalle`. Se llena en Sprint 2. Referencia: `bondiya/features/paradas/`.
- `buscar/components/` — buscador de estaciones/líneas. Se llena en Sprint 4. Referencia: `bondiya/features/buscar/`.

Ver `docs/plan-migracion.md` para el detalle de cada sprint y `todo-list.json` para el estado de cada tarea.
